# OCR 잔여 오인식 영역 재인식 실험

평가 범위: C004~C019, 기존 D-7 좌표 대응 및 정규화 정책 유지. 정답 문자열은 인식기에 전달하지 않았다. 원본 OCR은 변경하지 않았다.
개발용 오류 위치로 영역을 선택한 실험이다. 다른 문서의 자동 영역 선택 성능이나 법적 의미 보존을 입증하지 않는다.

| 방법 | Raw CER | Normalized CER | 추가 재인식 시간 |
|---|---:|---:|---:|
| 기존 대비 1.5배 | 12.4373% | 2.4976% | — |
| R1 | 12.6713% | 2.1206% | 6.03초 |
| R3_main_only | 12.4373% | 2.0264% | 6.03초 |
| R2 | 12.4707% | 2.3563% | 6.53초 |

R1: 대상 영역 2배 확대 + 대비 1.5배. R2: 3배 확대 + 원본 대비. 동일한 한국어 인식 모델을 직접 사용한다.
R3_main_only: R1의 실제 재인식 결과 중 본문 영역만 사용하고 특약은 기존 OCR을 유지한 별도 후보. GT 기반 문자열 교체는 없다.
R3은 R1 결과를 재사용하므로 별도 추론 시간을 측정하지 않았다. 위 시간은 전체 R1 재인식 비용이다.
기존 E02 OCR 195.48초 + R1 6.03초 = 합산 추정 201.50초. 이번 작업에서 전체 페이지 OCR을 재실행한 시간은 아니며 초기화·전처리·평가 시간도 제외했다.
R3 정규화 CER 상대 감소율: 18.87%. Raw CER는 동일하며 공백 오인식 증가가 문자 개선을 상쇄한다.

## 해결된 후보와 잔여 문제

- R1/R3에서 C004 `임차인이 부당하는 것으로 해석됨` → `임차인이부담하는것으로해석됨`. 실제 이미지 재인식 결과이며 문자열 치환이 아니다. 공백은 악화했다.
- R1/R3에서 C004 ①②③④, C007 ①, C008 ①②③, C010 ②를 인식했다. 임대인/임차인 등 용어 출현 횟수 차이는 0건이나 법적 의미 동등성 보장은 아니다.
- C014 날짜 밑줄 및 정확한 글머리표, C016 금액 밑줄, C017~C019 체크박스는 R3에서 해결되지 않았다.
- R2 C018에서 체크박스 하나를 인식했지만 다른 체크박스와 글머리표는 여전히 불완전하다. 체크 여부는 전혀 추정하지 않는다.
- 영상 형태 후보는 정사각형 471개, 수평선 9개다. 한글 글자와 표 테두리 등 다수 오탐을 포함하며 체크박스 검출 정확도로 해석할 수 없다. 문자/밑줄 개수를 합성하지 않았다.
- 모든 변경 후보는 needs_review. 자동 적용하지 않으며 기존 test_ocr.py 출력도 유지한다.

## 추가 검증 계획

이번 개발 문서를 제외한 개인정보 없는 합성 기입 계약서를 별도로 확보하고 사람이 정답·영역을 검증한다. 촬영, 회전, 흐림, 그림자, 글꼴, 금액·날짜·부정 표현·체크 상태를 나눈 독립 평가 세트에서 동일 설정을 고정해 평가한다. 숫자·주체·부정 표현 오류와 체크박스 검출 precision/recall도 CER와 별도로 측정한다. 그 전에는 이 후보를 기본 OCR로 자동 적용하지 않는다.
